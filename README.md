# RhizoCoast AI — Predictive Storm Warning Model

Machine learning pipeline for **RhizoCoast AI**, an artificial mangrove-inspired biochar seawall and coastal early-warning system. This model analyzes real-time barometric pressure, wind vectors, and tidal surge rates to predict incoming extreme weather up to 6 hours in advance

## Project Structure

* `download.py` — Fetches and merges multi-year historical weather (`KYWF1`) and hourly tide data (`8724580`) from NOAA for Key West, FL (2022–2024).
* `main.py` — Engineers atmospheric trend features, trains an XGBoost classifier on 2022–2023 data, evaluates performance on 2024 data, and exports the trained model.
* `main_single_year.py` — Single-year training baseline script.
* `rhizocoast_model.json` — Saved XGBoost model weights ready for hardware or web dashboard inference.
* `key_west_*.csv` — Processed datasets (generated by `download.py`).
* `requirements.txt` — Python dependencies.
* `.gitignore` — Excludes `.venv` and local environment files from version control.

## Quickstart

1. **Clone the repository and enter the project folder:**
   ```bash
   git clone https://github.com/levyzaraysky/RhizoCoastAI
   cd RhizoCoastAI
2. Create and activate the virtual environment (.venv):
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```
   (On Windows, run .venv\Scripts\activate instead)
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Download and prepare the NOAA dataset:
   ```
   python download.py
   ```
   (Generates key_west_2022_2024.csv)
5. Train, evaluate, and export the model:
   ```
   python main.py
   ```
   (Saves rhizocoast_model.json and runs a simulated live sensor alert check)
